# Seif & Shahd — Brand New Day

A little memory site for our Spider-Man day (30.7).

## How to publish this on GitHub Pages

1. Create a new repository on GitHub (e.g. `seif-and-shahd`).
2. Upload everything inside this folder — `index.html` and the `images/` folder — keeping the same structure.
3. Go to the repo's **Settings → Pages**.
4. Under "Build and deployment", set **Source** to `Deploy from a branch`, pick the `main` branch and `/ (root)` folder, then save.
5. GitHub will give you a live link after a minute or two, usually:
   `https://<your-username>.github.io/<repo-name>/`
